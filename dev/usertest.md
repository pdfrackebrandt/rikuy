# Galley user test session plan

One hour session for five people. The owner runs the sessions.

## Setup (5 min)
- Open Galley in a browser.
- Load a sample document from the corpus (e.g. a short paper or letter).

## Tasks (45 min)
1. Type a word at the end of a paragraph. Check it appears in the source.
2. Delete a word. Check only that word is removed from the source.
3. Bold a phrase (select and apply bold). Check the source has the correct markup and nothing else changed.
4. Edit inside math (change a symbol or number). Check the source math is updated correctly.
5. Edit a table cell. Check only that cell changes in the source.
6. Edit a footnote. Check the footnote text updates in the source.
7. Compile after each edit. Confirm the PDF updates and no unexpected errors appear.

## What to record
- For each task: success or failure, any unexpected source changes, any compile errors.
- Time spent on each task.
- Comments on the editing experience (lag, cursor position, unexpected behavior).

## Wrap-up (10 min)
- Overall impression.
- Any bugs or friction points.
- Would you use this instead of a local TeX install or Overleaf for short documents?
