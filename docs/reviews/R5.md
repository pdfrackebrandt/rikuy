# Hostile review of 411a0a7 (PR 68, task 65 R5)

Worktree `/home/claude/wt-r5-verify` (detached at 411a0a7), `dist/tex` hard linked from wt-r5-view and checked against `dev/dist-manifest.txt` (no difference), `npm run build` run there. Repro scripts and outputs in `/tmp/review-r5-out/`. Compiles: the results each script wrote, through desktop pdfTeX 3.141592653-2.6-1.40.25 (TeX Live 2023) with `-halt-on-error`. The errors are TeX's own and come from the macros, so the engine version does not change them.

## Verdict

**Changes needed.** Three bugs break a compile through ordinary Replace use. Two of them come from the new ^p code and one from the new Equation kind. The ruler has two mapping bugs and a keyboard bug. Rename can strand a document's pictures. Folding, Web Layout, the agent names and the speed check held up.

## High

**H1. Replacing ^p with nothing after a control word glues it to the next word: `\dotsNext`, compile error.** `src/cmd/find.js:453` (`gapEdit`). When the gap has no `%`, it is deleted outright with `t: ''`. Nothing looks at whether the text before ends in a control word. (escapeAt's `{}` guard only runs when there is replacement text. Typing's own join, `deletionEdits`, writes a space here.)
Repro (`attack_para.py`, cases dots_join, ldots_join, ss_join, S_join): Find `^p`, Replace with empty, Replace All.
- `See the end\dots\n\nNext para.` becomes `See the end\dotsNext para.` (`! Undefined control sequence. l.3 See the end\dotsNext`).
- `\ldots` becomes `\ldotsThen`, `Stra\ss\n\nweiter` becomes `Stra\ssweiter`, and `\S\n\nThree` becomes `\SThree`. All four fail to compile.

Fix: where `endsWithControlWord(src, x)` holds and the character after the gap is a letter, replace the gap with `{}` (or with a space, as `deletionEdits` does). Add a unit case for each of the four.

**H2. A ^p in the replacement is written inside an optional argument: `\item[La\n\nbel]`, compile error.** `src/cmd/find.js:469-481` (`breakFits`) counts `{}` and `$` but not `[...]`. The page's text of a description label or a theorem's name is "a paragraph's own text".
Repro (`attack_para.py` desc_label, thm_name):
- Find `Label`, Replace `La^pbel` in `\item[Label word]` writes `\item[La\n\nbel word]`, and the compile stops with `! Paragraph ended before \@item was complete.`
- Find `Name`, Replace `Na^pme` in `\begin{theorem}[Name here]` stops with `! Paragraph ended before \@ythm was complete.`

Fix: refuse when an unclosed `[` is open from the block's start, counting brackets the way braces are counted. Better still, refuse when the hit's characters belong to an item label or a theorem note (a FMT bit or a ctx on the page's element).

**H3. Format › Equation's Replace treats the LaTeX replacement as Word codes and finds letters inside command names.** `src/cmd/find.js:444-445`: `expandRep` runs before the `h.src` return, so `^p`, `^t`, `^s`, `^+`, `^-`, `^=` and `^~` are expanded inside a formula's LaTeX. `src/cmd/find.js:251` matches inside `\alpha` and `\frac`. Repro (`attack_eq.py`; compiles in `eq/build/`):
- In `$y = a+b$`, Find `y`, Replace `x^p` writes `$x\n\n = a + b$` (`! Missing $ inserted.`). The ^p never goes through breakFits on this path.
- In `$M = N$`, Replace `M` with `M^t` (a transpose) writes `$M<TAB> = N$`. It compiles, but the meaning is silently wrong.
- In `$\alpha = \frac{a}{2}$`, Replace All `a` with `b` writes `$\blphb = \frbc{b}{2}$` (4 hits; `! Undefined control sequence \blphb`).

Fix: in Equation mode (and arguably every `h.src` hit), take the replacement literally apart from the ^& and \n groups. Do not offer hits inside a control word (`\\[A-Za-z]+`) unless the query itself starts with `\`. On the find side, `x^p` and `A^t` in the box are also turned into codes, so the user cannot find them.

## Medium

**M1. The ruler moves the wrong margin on an even page of a two sided class.** `src/ui/ruler.js:330-333`: `mirrored` is true only when geometry's own `twoside` key is set. A `book`, or `article[twoside]` with `\usepackage[left=3cm,right=2cm]{geometry}`, is two sided: the page and geometry put the outer margin on the left of even pages.
Repro (`attack_ruler_web.py` even_*): on page 2 the ruler shows the left margin as 2 cm (the outer margin, correct). One ArrowRight on "Left margin" writes `left=2.25cm` (the inner margin, which was 3 cm). The even page's left margin stays at 2 cm and its right margin becomes 2.25.
Fix: `mirrored = !!m.two`, the layout's `g.twoside`, which already honours the class and `asymmetric`. Add a para/page test on a book.

**M2. A ruler slider loses focus after one arrow key, so the next arrow moves the caret in the text.** `src/ui/ruler.js:81-94`: after `apply`, `paraDialogApply` and `pageEdit` hand the focus back to the page. Repro (`ruler_focus.py`): focus "Left Indent" and press ArrowRight. Focus is now "Document". A second ArrowRight moves the caret from 191 to 192 and writes nothing. Two presses give 0.25 cm, not 0.5. The commit says the markers are "moved with the arrows (it is a slider by name)".
Fix: after apply, put the focus back on `R.M[k]` (it survives the relayout) and call `rulerSync`. Test two presses as two steps.

**M3. The First Line slider cannot be moved with the keys at all.** `src/ui/ruler.js:310`: from `\parindent` (15 pt), one step of 0.25 cm (7.1 pt) lands at 7.9 pt. That is still past `Q + parindent/2` (7.5 pt), so the result is 'first' again: no edit. Shift's 0.05 cm steps never accumulate either. Repro: `attack_ruler_web.py` ind_first_ArrowLeft and ArrowRight, each 0 steps of history.
A related problem: dragging Hanging right by less than the first line puts both into `adjustwidth` (line 305, `special = 'first'; l = v`), so the first line moves too, against the comment "the first stays where it is". Run `ind_hang_ArrowRight` and the first line goes from 15 to 22 pt.
Fix: for the keys, move between the three states ('hanging' / 'none' / 'first') one per press. For Hanging between 0 and F, use hanging from l=0 or refuse with a note.

**M4. Rename that fails halfway strands the pictures and still says "Renamed".** `src/cmd/file.js:338-341`: versions move in one transaction, then each `bin:`/`link:`/`share:`/`scripts:` record moves in its own put and delete, and any failure is swallowed. Repro (`attack_rename.py`): make the put of `bin:New|main.tex` throw QuotaExceededError (the case where storage is full). The snaps are named New and link: has moved, but `bin:Old|main.tex` (the pictures) stays under a name no document has, and the toast says "Renamed Old to New." Opening New loads no pictures (`loadBinary` keys by name).
Fix: move the snaps and every kv record in one IndexedDB transaction over both stores (same DB). If that is not possible, undo the snaps' rename on failure and say so.
Related (Low, two tabs): the check that the name is free (`:331`) and the move are not atomic. `Promise.all([renameRecent('A','Same'), renameRecent('B','Same')])` merges both documents' versions under Same, and `bin:Same|main.tex` ends up holding B's pictures. A's pictures are deleted.

**M5. Go To, Next comment and the Navigation pane do not open a collapsed heading.** Only Find (`findShow`) and `rebuild(caret)` call `foldReveal`. Repro (`attack_fold2.py`):
- Go To label/section/comment under a collapsed Beta returns `ok` and puts the caret in the hidden text. Nothing on the page shows it (`goTo` falls back to the source pane). The first keystrokes then land there, and only after that does the section open.
- A click on "Beta sub" in the Navigation pane's Headings does nothing visible, and the keys typed next went nowhere.

Fix: call `foldReveal` (pred: the item whose block holds f,p) in `goToTarget`, in nav's `goTo`, and in Review's Previous/Next comment and change, before restoring the caret.

## Low

- **L1.** A `{\bfseries a.\n\nb.}` group: the soft break inside the group is not offered, only the hard one after it (`attack_para.py` bfgroup). This is a missed mark, nothing more.
- **L2.** Fold state survives across a different document with the same name|main (Remove does not delete `rikuy.fold.v1`'s entry, `src/cmd/file.js` remove path). A later document of that name gets its headings collapsed by matching words. Two tabs on one document overwrite each other's fold list (`foldSave`, last writer wins).
- **L3.** Move down (Alt+Shift+Down) of a collapsed section expands it (`attack_fold3.py` move_after). Word keeps it collapsed. This happens because foldMap's single diff puts the place at the hunk's start and matchFold then finds nothing.
- **L4.** On a phone, the 44 px triangle beside a heading that wraps sits after the last line, but its box overlaps the line above's rect (`attack_phone.py` 390_tri and 360_tri, overlapsHeadingText 2). A tap meant for the words there collapses the section instead. The Rename dialog's Close button is 20x20 at 390 and 360 px (the shared `guide()` pop's button, probably not new).
- **L5.** A selection across a collapsed heading deletes the hidden text too (`attack_fold2.py` sel_del_*: the same bytes as with it open). One Undo gives everything back. This is Word's behaviour, but nothing warns. Mention it in the docs, or confirm when the selection holds hidden text.
- **L6.** Ruler markers are 11x5 to 7 px targets. That is mouse only and Word's size, but below WCAG 2.5.8's 24 px.

## What held up

- ^p hard/soft: `\section`, `\noindent`, `\item` with a blank line, `\par`, braces: hard or no mark, never replaced (bfgroup, sec_after, noindent, enumerate_items, par_cmd). A comment at a line's end (`First words. % a note\n\nSecond`) keeps its line end, so no text becomes a comment (comment_eol, comment_eol_x, pct_eol). Verbatim gives no hits and no edits. ^p in the replacement is refused in a heading, `\paragraph`, a cell, a caption, a footnote, `\textbf`, `\underline`, `\mbox`, `\fbox`, `\href`, `\title` and `\author`. center, quote, minipage and item joins compile. All 37 cases except H1 and H2 compile.
- Folding: the place follows edits typed before the heading (s 75 to 103). Enter at the end of a collapsed heading opens it, so nothing is typed blind. Undo of a keystroke under a heading collapsed afterwards opens it and gives the bytes back. Duplicate headings: deleting the first "Results" keeps the second collapsed. Track Changes with a collapsed section: nothing breaks, and the fold drops when its heading empties. 1500 headings collapsed: 56 ms against 48 ms for a commit and a frame. Expand all takes 0.05 s.
- Web Layout: no 1e6 pt sheet in the DOM (`height:auto`), footnotes beside their text, `\newpage` makes a second sheet, TOC numbers shown, Go To page 2 works, it reflows to 644 px at 700 px, and at 390 and 360 px there is no sideways scroll.
- Ruler: off with reasons in a heading and a list item. The command is disabled on touch with its reason. Indent round trips leave only `\usepackage{changepage}` behind (allowed by the round trip rule).
- Phones: Format's new kinds and Special › Paragraph mark are 44 px items. The Rename dialog fits at 360 and its field and buttons are 44 px.
- `npm run test:agent`: 143 passed, 0 failed. `page.py long_document`: every command's when/on together take 24 ms (under 40), none over 5 ms.
